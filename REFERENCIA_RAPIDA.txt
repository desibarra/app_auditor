┌──────────────────────────────────────────────────────────────────────┐
│  ⚡ INICIO RÁPIDO                                                     │
└──────────────────────────────────────────────────────────────────────┘

  1. Abre Docker Desktop (ícono de ballena verde)
  2. Ejecuta: START_PRODUCTION.bat
  3. Accede a: http://localhost:3000

  ⏱️  Primera vez: 5-10 minutos
  ⏱️  Siguientes veces: 10-15 segundos


┌──────────────────────────────────────────────────────────────────────┐
│  📁 SCRIPTS PRINCIPALES                                               │
└──────────────────────────────────────────────────────────────────────┘

  ⭐ START_PRODUCTION.bat          Inicio rápido (USA ESTE)
  📋 MANAGE_PRODUCTION.bat         Menú interactivo
  🔧 DEPLOY_PRODUCTION.bat         Despliegue completo
  ✔️  VERIFICAR_PRODUCCION.bat     Verificar configuración


┌──────────────────────────────────────────────────────────────────────┐
│  🌐 URLS DE ACCESO                                                    │
└──────────────────────────────────────────────────────────────────────┘

  Frontend:     http://localhost:3000
  Backend:      http://localhost:4000
  Health:       http://localhost:4000/api/health


┌──────────────────────────────────────────────────────────────────────┐
│  🎮 COMANDOS ESENCIALES                                               │
└──────────────────────────────────────────────────────────────────────┘

  Iniciar:
    START_PRODUCTION.bat

  Detener:
    docker-compose -f docker-compose.prod.yml down

  Ver logs:
    docker-compose -f docker-compose.prod.yml logs -f

  Ver estado:
    docker-compose -f docker-compose.prod.yml ps

  Reiniciar:
    docker-compose -f docker-compose.prod.yml restart

  Reconstruir:
    docker-compose -f docker-compose.prod.yml build --no-cache


┌──────────────────────────────────────────────────────────────────────┐
│  💾 BACKUPS                                                           │
└──────────────────────────────────────────────────────────────────────┘

  Crear backup:
    MANAGE_PRODUCTION.bat → Opción 7

  Restaurar backup:
    MANAGE_PRODUCTION.bat → Opción 8

  Backup manual:
    docker cp sentinel-backend-prod:/app/data/saas_fiscal.db backups/


┌──────────────────────────────────────────────────────────────────────┐
│  🐛 SOLUCIÓN RÁPIDA                                                   │
└──────────────────────────────────────────────────────────────────────┘

  ❌ Docker no está corriendo:
     → Abre Docker Desktop y espera a que inicie

  ❌ Puerto en uso:
     → docker-compose -f docker-compose.prod.yml down

  ❌ Error al construir:
     → docker system prune -f
     → START_PRODUCTION.bat

  ❌ No carga el frontend:
     → docker-compose -f docker-compose.prod.yml logs frontend

  ❌ Backend no responde:
     → docker-compose -f docker-compose.prod.yml logs backend

┌──────────────────────────────────────────────────────────────────────┐
│  ⚙️  GESTIÓN AVANZADA                                                 │
└──────────────────────────────────────────────────────────────────────┘

  Entrar al contenedor backend:
    docker exec -it sentinel-backend-prod sh

  Entrar al contenedor frontend:
    docker exec -it sentinel-frontend-prod sh

  Ver volúmenes:
    docker volume ls

  Limpiar sistema:
    docker system prune -a -f

  Ver imágenes:
    docker images
